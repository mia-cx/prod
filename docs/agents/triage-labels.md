# Triage metadata

Use the repository's existing labels. Do not create a second label vocabulary solely to distinguish autonomous and human work.

| Workflow role | Repository representation |
| --- | --- |
| Needs triage | Leave without a readiness marker; use `⚠️ action needed` only when genuinely urgent |
| Needs information | Record the blocking question in the issue body or comments |
| Ready for agent | `Execution: AFK` in the issue body |
| Ready for human | `Execution: HITL` in the issue body |
| Won't fix | `🙅 wontfix` |

GitHub Issue Types provide the primary classification. Approved implementation slices use `📋 task`.
